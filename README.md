# Miel — personal portfolio

React + TypeScript portfolio hosted on GitHub Pages.

- [Cum adaugi poze în galerie sau tierlist — ghid în română](tcnsite/IMAGES_GUIDE.md)
- [Project setup and deployment](tcnsite/README.md)
- [Content and page editing guide](tcnsite/PAGE_GUIDE.md)
- [Riot statistics service](tcnsite/integrations/riot/README.md)

Run application commands from `tcnsite/`. Content and appearance settings live in `tcnsite/data/`.

Pentru o poză nouă: copiază originalul în folderul colecției, adaugă cardul în JSON și rulează `npm run optimize:images` din `tcnsite/`. Nu creezi manual miniaturi sau WebP-uri. [Ghidul de imagini](tcnsite/IMAGES_GUIDE.md) explică exact folderele, câmpurile și publicarea.
